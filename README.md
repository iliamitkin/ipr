# Листва — магазин растений

Учебный frontend-магазин на Vue 3, TypeScript, Vue Router, Pinia и SCSS.

## Запуск

```sh
npm install
npm run dev
```

Production-сборка: `npm run build`.

## Структура

- `src/api` — адаптер демо-оформления заказа; при подключении backend замените его реализацию.
- `src/assets` — локальные SVG-изображения и SCSS.
- `src/components` — переиспользуемые компоненты с локальными стилями.
- `src/config` — роутер и данные каталога.
- `src/helpers` — форматирование цен.
- `src/hooks` — composables, например фильтрация и сортировка каталога.
- `src/pages` — страницы, загружаемые лениво по маршруту.
- `src/providers` — создание Pinia.
- `src/store` — Pinia-хранилища корзины и избранного.
- `src/types` — общие TypeScript-типы.

Каталог, избранное и корзина демонстрируют состояние и взаимодействия на стороне клиента. Данные корзины и избранного сохраняются в `localStorage`.
